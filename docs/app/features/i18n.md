# i18n

## What This Feature Does

Built-in i18n gives you localized routing, generated typed message keys, and a
request-scoped translation context without runtime JSON parsing on startup.

The source files live under `web/i18n/messages`. Generation emits:

```text
web/generated/i18n
web/generated/i18n/messages
```

## Modules

- `framework/i18n`
- `internal/bundler/i18ngen`
- `internal/projectlayout`

## Happy Path

Define locale policy in `web/i18n/settings.go`:

```go
func Config() frameworki18n.Config {
	return frameworki18n.Config{
		Locales:       []string{"en", "de"},
		DefaultLocale: "en",
		PrefixMode:    frameworki18n.PrefixAsNeeded,
	}
}
```

Define message shards in `web/i18n/messages/*.json`:

```json
[
  {
    "id": "seo.author.description",
    "translation": "Browse notes by {{.Author}}.",
    "args": [
      { "name": "Author", "type": "string" }
    ]
  }
]
```

You can split messages across multiple locale files such as
`layout.en.json`, `seo.en.json`, and `notes.en.json`. The generator merges them
per locale and rejects duplicate IDs.

## Focused Example

Use the generated typed helpers in app code:

```go
import i18n "your-app/web/generated/i18n"

func MetaGenAuthorPage(
	meta framework.MetaContext[*runtime.Context],
	slug string,
) (metagen.Metadata, error) {
	tr := meta.App().I18n(meta.Request())

	return metagen.Metadata{
		Description: i18n.TSeoAuthorDescription(tr, i18n.SeoAuthorDescriptionArgs{
			Author: slug,
		}),
	}, nil
}
```

The request-scoped translation context also owns localized paths and locale
switch URLs:

```go
tr := meta.App().I18n(meta.Request())
notesURL := tr.URLFor("de", "/notes")
switchToEnglish := tr.SwitchURL("en")
```

## When To Use `Custom Config` Or Advanced Composition

If `web/i18n/messages` exists, built-in i18n is the normal path.

If you need a different localization system, disable built-in i18n in
`no-js.bundle.yaml`:

```yaml
version: 1

i18n:
  mode: disabled
```

Then keep using the routing and server primitives from `no-js`, but own the
localization layer in app code.
