# i18n

Use this guide when your app needs localized routing and typed translations.

## What This Feature Does

Built-in i18n gives you:

- locale-aware routing
- generated typed translation keys
- request-scoped translation helpers
- localized path and switch-URL helpers

When built-in i18n is enabled, generation writes:

```text
web/generated/i18n
web/generated/i18n/messages
```

## Happy Path

Define locale policy in `web/i18n/settings.go`:

```go
package webi18n

import frameworki18n "github.com/RevoTale/no-js/framework/i18n"

func Config() frameworki18n.Config {
	return frameworki18n.Config{
		Locales:       []string{"en", "de"},
		DefaultLocale: "en",
		PrefixMode:    frameworki18n.PrefixAsNeeded,
		DisplayLabels: map[string]string{
			"en": "English",
			"de": "Deutsch",
		},
		DisplayOrder: []string{"de", "en"},
	}
}
```

Define message shards in `web/i18n/messages/*.json`:

`seo.en.json`

```json
[
  {
    "id": "seo.author.description",
    "translation": "Browse notes by {{.Author}}.",
    "args": [
      { "name": "Author", "type": "string" }
    ]
  }
]
```

`seo.de.json`

```json
[
  {
    "id": "seo.author.description",
    "translation": "Notizen von {{.Author}} lesen."
  }
]
```

Run generation:

```bash
go tool no-js gen routes -root .
```

## App Context Integration

Expose the generated request-scoped i18n context from your app context:

```go
func (c *Context) I18n(r *http.Request) frameworki18n.Context[i18n.Key] {
	return messages.NewContext(r, c.ResolveRoot(r))
}
```

That gives resolvers access to translations and localized URLs on the current
request.

## Using The Generated Typed Helpers

```go
func (Resolver) MetaGenAuthorParamSlugPage(
	meta framework.MetaContext[*runtime.Context],
	params AuthorParamSlugParams,
) (metagen.Metadata, error) {
	tr := meta.App().I18n(meta.Request())

	return metagen.Metadata{
		Description: i18n.TSeoAuthorDescription(tr, i18n.SeoAuthorDescriptionArgs{
			Author: params.Slug,
		}),
	}, nil
}
```

The request-scoped context also owns localized paths and language-switch links:

```go
tr := meta.App().I18n(meta.Request())
notesURL := tr.URLFor("de", "/notes")
switchToEnglish := tr.SwitchURL("en")
```

## Prefix Modes

- `always`
  Always prefix routes with the locale.
- `as-needed`
  Prefix non-default locales only.
- `never`
  Never prefix routes with the locale.

Current locale codes are normalized to two-letter lowercase forms.

## Disabling Built-In i18n

If your app uses a different localization system, disable built-in i18n in
`no-js.bundle.yaml`:

```yaml
version: 1

i18n:
  mode: disabled
```

Then keep using `no-js` routing and runtime features while owning localization
in app code.
